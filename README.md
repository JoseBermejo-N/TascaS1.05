# 🐘 PHP Object-Oriented Programming (OOP) - Part 2
Welcome to my PHP learning repository for the second part of OOP! This space is dedicated to collecting practical exercises, code challenges, and OOP concepts that I develop as I progress through my training by ITAcademy.

## 🚀 Development Environment
- **PHP** (Version 8.2.12)
- **Editor:** Visual Studio Code
- **Recommended Extension:** PHP Server (or whichever extension you use to run them)

## 📂 Repository Structure
The project is organized by difficulty levels for easy navigation:

- **nivel1/**
  - `Ejercicio 1`: Animal class structure where different animals "talk" using class inheritance.
  - `Ejercicio 2`: `Shape` base class inherited by `Triangle` and `Rectangle` to calculate their areas.
- **nivel2/**
  - `Ejercicio 1`: Extension of the previous exercise adding a `Circle` class and adapting the area calculation.
- **nivel3/**
  - `Ejercicio 1`: Notification system using `Email`, `SMS`, and `OrdinaryMail` based on an abstract class.

## 🛠️ How to Run This Project
If you want to test these exercises in your local environment using Visual Studio Code, follow these steps:

1. **Clone this repository:** https://github.com/JoseBermejo-N/TascaS1.05.git
2. **Open the folder in your editor:** Open Visual Studio Code, go to File -> Open Folder, and select the cloned repository folder.
3. **Run the files:**
   - Open any `.php` file.
   - Right-click inside the editor and select "Run code".
